# 🚀 ChatGPT 左侧悬停展开 + 仿原生右侧对话目录导航

> **专为沉浸式长对话设计**：启动自动收起左侧栏，贴边悬停无感呼出；自带高颜值仿原生右侧目录导航，支持全量历史问题索引与平滑跨页定位，原生导航存在时自动让位保护！

---

### ✨ 核心痛点与解决方案

- ❌ **痛点 1：左侧栏太占空间，频繁手动收起/展开太麻烦？**  
  👉 **方案**：页面加载自动收起侧边栏，保留最大工作视野；当鼠标靠近屏幕最左侧（18px 区域）悬停 100ms 自动平滑展开，移出侧栏 250ms 自动收起，交互丝滑自然，不覆盖破坏页面原生布局。
- ❌ **痛点 2：长对话翻找提问极其痛苦，原生右侧导航经常“失踪”或只加载了局部问题？**  
  👉 **方案**：内置仿原生右侧问题目录导航，自动回溯当前分支的完整提问；默认展示极简短横线指示器，悬停或聚焦时向左展开精美圆角抽屉列表；点击未渲染的早期问题可自动模拟滚动并跨页精准定位！

---

### 🌟 特性一览

#### 1. 🧭 左侧侧边栏智能悬停控制
- **零全局污染**：直接复用并触发 ChatGPT 原生展开/收起按钮逻辑，不硬改全局 CSS，不破坏响应式布局。
- **平滑防误触**：左边缘停留 100ms 激活展开；鼠标移出 250ms 自动收起，在此延迟内移回可撤销关闭，操作容错率高。
- **宽屏与设备保护**：仅在桌面端宽屏环境启用，触屏或窄屏移动设备自动回退，不干扰正常触控。
- **页面状态自适应**：无论是手动打开、悬停展开还是页面跳转自动展开，均统一管理收起生命周期。

#### 2. 📌 仿原生右侧对话目录（备用导航）
- **双重视觉形态**：
  - **默认极简模式**：右侧居中排列紧凑短横线（tick），一条横线对应一个用户提问，当前阅读的问题刻度加粗加亮。
  - **悬停抽屉展开**：鼠标移入时向左平滑展开圆角列表，逐行展示问题完整文本（长标题单行优雅省略）；支持独立滚轮滑动。
- **全量分支索引回溯**：
  - 自动读取当前分支完整链路，不再局限于屏幕已渲染的少量消息。
  - 支持多页长对话沿游标回溯、消息去重、分支变更每分钟轻量同步。
- **平滑智能定位**：
  - 点击早期未挂载的消息时，脚本自动小步滚动触发 ChatGPT 虚拟滚动加载机制，并在元素挂载后比对消息 ID 精准锁定。
  - 定位支持超时保护与随时打断（Esc、鼠标滚轮、触控或会话切换均可立即取消）。
- **深浅主题自适应**：
  - 原生匹配 Light / Dark 模式无缝跟随切换，阴影与边框过渡自然。

#### 3. 🛡️ 原生导航保护机制
- **优先官方原生**：如果 ChatGPT 官方原生右侧导航生效且可见，备用导航自动隐藏让位；原生导航消失 2 秒后备用导航平滑顶替，互不冲突。
- **多种模式可选**：支持强制显示备用、自动接管、或彻底关闭备用。

#### 4. ⌨️ 全键盘无障碍支持
- 按 `Tab` 键聚焦右侧导航时自动展开列表。
- `↑` / `↓`（方向键）或 `Home` / `End` 切换选中条目。
- `Enter` 或 `Space` 立即跳转定位。
- `Esc` 快速关闭展开抽屉并取消定位。

### ⚙️ 菜单与快捷设置

在浏览器中点击 **Tampermonkey（油猴）扩展图标**，展开脚本菜单即可直接切换配置（设置自动持久化保存）：

| 菜单项 | 功能说明 | 适用场景 |
| :--- | :--- | :--- |
| **右侧导航：自动（优先原生）** | 默认推荐模式。检测到原生导航时隐藏，原生消失时接管 | 日常使用最佳体验 |
| **右侧导航：强制显示备用** | 始终显示脚本内置的备用导航 | 原生导航虽然存在但卡死/不可点击/只显示部分问题时 |
| **右侧导航：关闭备用** | 仅保留左侧悬停功能，完全禁用右侧备用导航 | 只想使用原生导航或不需要右侧导航时 |
| **重新读取完整会话索引** | 立即发起当前会话分支的索引重试与同步 | 切换了分支版本、网络波动失败或刚补充长内容后 |
| **立即收起左侧栏** | 手动执行一次收起侧栏操作 | 临时快速整理页面窗口 |
| **查看脚本状态** | 打开浮层诊断窗口，查看当前识别状态与网络阶段 | 遇到异常排查原因，并支持**一键复制诊断日志** |

### 🔒 隐私与安全承诺

1. **绝对纯净与透明**：本项目完全开源，代码纯净独立，**不引入任何外部第三方库或 CDN 资源**。
2. **零第三方请求**：不会将任何对话、账号或浏览数据发送到 GitHub 或任何第三方统计/分析服务器。
3. **内存级会话凭证**：会话 Token 仅在当前标签页向官方接口发起同源请求链时在临时内存中使用，**绝不保存至油猴本地存储（GM_storage），绝不输出到 Console 日志**。
4. **安全沙箱**：UI 采用 Shadow DOM 隔离渲染，避免与页面样式发生冲突或相互污染。

### ❓ 常见问题（FAQ）

<details>
<summary><b>Q1: 为什么右侧导航偶尔提示“403”或“正在读取完整历史”？</b></summary>

> ChatGPT 后端对于部分长对话或某些工作区使用了较严格的权限校验与频控策略。脚本内置了多种回退机制（完整消息树 ➔ 兼容消息树 ➔ 游标分页入口），并且会自动复用当前会话的上下文凭证。遇到 403 时脚本会尝试退避重试；即使未能拉取到全量远端索引，页面上已加载的问题依然可以正常显示与点击定位。
</details>

<details>
<summary><b>Q2: 为什么鼠标停在最左侧时侧边栏没有展开？</b></summary>

> 1. 请检查屏幕分辨率：脚本设置了桌面最小宽度保护（默认窗口宽度小于 768px 或触屏设备时不激活，以防移动端冲突）。
> 2. 请确认鼠标是否靠紧窗口最左边缘（18 像素以内），并稍作停留约 100 毫秒。
> 3. 点击油猴菜单中的“查看脚本状态”，检查是否成功抓取到 ChatGPT 的展开/收起按钮。
</details>

<details>
<summary><b>Q3: 我只想要左侧悬停，不想要右侧导航怎么办？</b></summary>

> 点击 Tampermonkey 扩展图标，在菜单中选择 **「右侧导航：关闭备用」** 即可。配置会自动保存，刷新页面也生效。
</details>
